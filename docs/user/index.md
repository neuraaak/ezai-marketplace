# User guide

This guide is for **people who use AI coding agents** and want the curated ezai skills
available in them. It assumes no knowledge of how ezai-marketplace is built. If you are
contributing to ezai-marketplace itself, read the
[developer documentation](../getting-started.md) instead.

`ezai` is a command-line tool. Every step below is a command you type in a terminal.

## 🚀 Quick start

[Get started](./get-started.md) — install the CLI and put every curated skill in place in
under two minutes.
