# Guides

One page per thing you can do with `ezai`. Each page lists what you need, the exact
commands, and what you should see afterwards.

All pages assume the CLI is installed globally (`npm install -g ezai-marketplace`); if it
is not, start with [Get started](../get-started.md).

## 📚 Everyday tasks

| Task                                                | When you do it                                      |
| :-------------------------------------------------- | :-------------------------------------------------- |
| [Find a skill before installing](./find-a-skill.md) | You want to browse or search the catalogue first    |
| [Install skills](./install-skills.md)               | You want every skill, or one skill by name          |
| [Update installed skills](./update-skills.md)       | You upgraded the package and want the new catalogue |
| [Remove a skill](./remove-a-skill.md)               | You no longer want a skill on your machine          |

## 📚 Choosing where things go

| Task                                                                    | When you do it                                        |
| :---------------------------------------------------------------------- | :---------------------------------------------------- |
| [Choose whether a platform link is created](./choose-platform-links.md) | You want to skip the Claude Code link                 |
| [Install to a shared directory](./install-to-a-shared-directory.md)     | Several accounts or projects share one skills store   |
| [Use a remote catalogue](./use-a-remote-catalogue.md)                   | Your team publishes its own skill list                |
| [Set up on Windows](./set-up-on-windows.md)                             | You are on Windows, with or without Node.js installed |
